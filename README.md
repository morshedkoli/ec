# 🗳️ EC Management — Electoral Records & Center Management Portal

[![Next.js](https://img.shields.io/badge/Platform-Web_Application-black?style=for-the-badge&logo=next.js)](https://nextjs.org/)
[![TypeScript](https://img.shields.io/badge/Language-TypeScript_|_JavaScript-blue?style=for-the-badge)](https://www.typescriptlang.org/)
[![License](https://img.shields.io/badge/License-MIT-green?style=for-the-badge)](LICENSE)

A secure data management platform for organizing voter listings, polling station inventories, election officers, and logistical resources.

---

## 🌟 Key Features

- **Polling Station Management**: Map polling venues with voter capacity and room allocations.
- **Officer Assignments**: Assign presiding officers and polling staff with automated contact rosters.
- **Logistics Tracker**: Inventory tracking for ballot boxes, security stamps, and election supplies.

---

## 🛠️ Technology Stack

- **Technology**: Next.js, React, PostgreSQL

---

## 🚀 Getting Started

```bash
# 1. Clone repository
git clone https://github.com/morshedkoli/ecmanagement.git

# 2. Install dependencies
npm install

# 3. Launch application
npm run dev
```
